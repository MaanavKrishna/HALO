# Pages

| Route | Shows | Data |
|---|---|---|
| `/` | Habitat builder; submits to `/brief`. | presets, manifest counts |
| `/brief?...` | The Fire Brief for a habitat query. | engine over all data |
| `/explore` | PageHero ("{n} investigations. Every one cited.", count and readouts from data) over an instrument table: sticky glass header under the nav, sortable columns with `aria-sort`, hazard filter as ToggleChips (any selected hazard matches), fuel class as a Segmented, live result count. Each row has an O2 coverage bar on a fixed 0–40% track with the Moon envelope's O2 band (from `PRESETS.moon`) hatched. Below 1024px: cards with the same bar. View toggle List / Patches: a mission-patch grid (own geometric glyph per hardware family, the O2 gauge as the ring; no agency insignia). Null ranges read "not tabulated". | `investigations.json`, manifest counts |
| `/explore/[psiId]` | Dossier. Hero: acronym, PSI id, hardware family, title, fuel-class chips, dataset DOI. Left: SI summary and habitat relevance (only if present and not needsReview; each sentence carries SiChip), objective, research impact, varied and fixed variables, the O2 x pressure plot (brief chart language: hairline grid, mono ticks, Moon envelope box, ISS and Artemis reference crosshairs; filled = measured, hollow = inferred/assumed; data-table fallback), publications with DOI links (first 10, rest behind a disclosure), prev/next by PSI number. Right (first on phones): sticky spec sheet with mission patch, O2/pressure/flow ranges as Stats, rows/eligible/papers, hazards, license, dates and "Open in PSI". Statically generated for every id. | `investigations.json`, `tests.json` (joined on psiId), `summaries.json` |
| `/compare?a=<query>&b=<query>` | Hero headline "What changes when you move from A to B" with a swap action. Preset pickers as two Segmented controls (ISS, Artemis, Moon, Rover, EVA suit; a Custom option appears for non-preset habitats) that navigate without a scroll jump. Two mission cards (GradeBadge, O2/pressure/flow Stats, flags with status lamps and "Only here" marks, smoke-detection meters) around a centre delta rail computed by `compareDelta`: grade change and direction, atmosphere deltas, flags gained/cleared/carried, detection share. On phones the rail comes first. URL notices show in an info Callout (`role=note`, name "Notices"). `a` and `b` are habitat query strings as built by `habitatToQuery`; defaults are the ISS and Artemis Base presets. | engine (`buildBrief`), `detector.json` ambient |
| `/about` | Method and disclosures. | n/a |

Notes
- Acronyms differ between `tests.json` and `investigations.json`; always join on `psiId`.
- Unknown `/explore/<id>` returns a real 404. With Cache Components a `notFound()` inside the page would stream under a 200, so `next.config.ts` rewrites ids absent from the data to a missing route before rendering. `notFound()` stays as a fallback (for example a lower-case id, which still matches the route and shows the not-found page with a noindex tag).
- Text from data is rendered as plain text; external links use `rel="noopener noreferrer"`.
